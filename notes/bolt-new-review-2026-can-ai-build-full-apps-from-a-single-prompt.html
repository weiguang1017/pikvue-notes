Bolt.new is an AI-powered web app builder from StackBlitz that generates complete, runnable applications from a single text prompt. Unlike code assistants that suggest snippets, Bolt.new aims to produce entire projects — frontend, backend, and deployment config — in one shot. It runs generated code directly in the browser via WebContainers, giving instant visual feedback with no local setup required.
